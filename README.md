# Topology Star

Proyek ini berisi file topologi jaringan tipe Bintang (Star Topology) yang dibuat menggunakan Cisco Packet Tracer.

## Cara Penggunaan

1. Buka aplikasi Cisco Packet Tracer (direkomendasikan versi 8.x atau yang lebih baru).
2. Pilih `File > Open` dan pilih file `TOPOLOGY STAR.pkt` yang ada di dalam folder proyek ini.
3. Anda dapat melihat simulasi jaringan dan melakukan tes koneksi antar node dalam topologi bintang.
